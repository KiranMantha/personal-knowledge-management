## 1. The Problem Every Freelancer Has

When you’re freelancing, there’s only one problem that really matters:  
 **Finding consistent clients.**

I loved coding in Python, but I hated pitching.  
 Writing cold emails, searching LinkedIn, scraping leads — it was draining.

So I thought: *“If I can automate spreadsheets and emails for clients, why not automate finding clients too?”*

Three days later, I had built a Python bot that found leads, scored them, wrote cold emails, and even sent them automatically.

## 2. The Stack That Made It Work

I kept it simple:

* **Requests + BeautifulSoup** → Scrape Google Search
* **OpenAI API** → Write personalized emails
* **smtplib** → Send emails automatically
* **SQLite** → Store leads
* **schedule** → Run it every morning
