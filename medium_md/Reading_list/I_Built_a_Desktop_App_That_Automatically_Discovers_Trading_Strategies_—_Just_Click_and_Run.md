If you’ve ever tried to backtest a trading strategy from scratch, you know the friction.

Download data. Write indicator logic. Run in-sample. Run out-of-sample. Run a holdout period. Then run Walk-Forward Optimization. Then Monte Carlo. Then wonder if you set up the splits correctly.

That’s before you’ve even looked at the results.

I built the [**Simple Indicators Strategy Generator — Python Code Bundle (Lite / Free Version)**](https://kryptera.gumroad.com/l/qlmvfl) to automate the discovery part — randomly searching thousands of indicator combinations and keeping only those that beat the benchmark across 3 separate validation periods. It works. People use it. It saves hours.

But it still required you to open a Python file, change a variable, and run a script.

That’s not friction for me. It might be for you.

So I turned it into a desktop app.
