## 1. `/edit` — The Command That Replaced Copy‑Paste Hell

In the beginning, I would paste a file, ask Claude to modify it, and then manually merge the changes back into my project. This was slow, error‑prone, and honestly exhausting.

The `/edit` command eliminates that entire process.

Instead of rewriting the file manually, you tell Claude exactly what to change, and it updates the file directly. This keeps the context of the file intact and avoids accidental deletions or formatting issues.

Example:

```
/edit src/services/UserService.java  
Add null checks before accessing user.getEmail()
```

Claude applies the change in place. No scrolling, no copy‑paste, no guessing where to insert code.

This single command removed one of the biggest friction points in AI‑assisted coding.
